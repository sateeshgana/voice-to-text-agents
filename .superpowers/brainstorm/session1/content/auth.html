Do users need to log in or create accounts?

Authentication affects privacy, history features, and deployment complexity.

🚀

No Login Required

Anyone opens the URL and starts recording immediately. No signup friction. Transcriptions are session-only — not saved between visits. Recommended for maximum reach.

✓ Zero friction ✓ No backend user management ✓ Privacy-friendly
👤

Optional Login (Save History)

Works without login, but users can sign in to save transcription history across sessions. Login via Google/GitHub OAuth (Netlify Identity — free tier).

✓ Saves history ⚠ More complexity
🔒

Login Required

Users must sign in before using the app. Full history saved. Suitable for enterprise/organization use where access control matters.

✓ Access control ✗ High friction ⚠ Most complex
