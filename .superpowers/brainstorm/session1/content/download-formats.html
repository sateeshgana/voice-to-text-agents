What output formats should users be able to download?

Select all that apply — copy-to-clipboard is always included.

📄

Plain Text (.txt)

Simple, universal, smallest file size. Works in every app. Always included.

📝

Word Document (.docx)

Familiar for office workers. Preserves formatting. Useful for formal documents, reports, letters in Indian languages.

📕

PDF (.pdf)

Print-ready, non-editable. Good for sharing final transcripts. Requires a PDF library (jsPDF).

🎬

Subtitle File (.srt)

Timestamped subtitles — useful if recording long audio and need timed captions for video content.
