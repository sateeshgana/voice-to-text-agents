How should Speech-to-Text work?

This is the most important architectural decision — it affects cost, accuracy, and offline capability.

🌐

Browser Web Speech API (Primary)

100% free, zero backend — uses Chrome/Edge's built-in speech recognition. Supports Hindi, Tamil, Telugu, Bengali and more. Works instantly, no server needed. Falls back to Groq Whisper API (free tier: 7,200 sec/day) when browser API fails or language unsupported.

✓ Zero cost ✓ No backend needed ⚠ Chrome only for best results
⚡

Groq Whisper API (Primary)

Best accuracy, free tier — Groq runs OpenAI Whisper at blazing speed. Free tier gives 7,200 seconds/day. Requires a Netlify serverless function to proxy the API key. Falls back to browser Web Speech API when quota exhausted.

✓ Highest accuracy ✓ All languages ⚠ Needs serverless function
🇮🇳

Bhashini API (Indian Gov — Primary)

Best for Indian languages — India's official free AI translation & STT platform built for all 22 scheduled languages. Trained specifically on Indian accents. Requires free registration. Falls back to Groq Whisper. Recommended for production Indian language apps.

✓ Best Indian accuracy ✓ All 22 official languages ⚠ Registration required

Python fallback note: All 3 options can fall back to a Python Netlify Function running faster-whisper or SpeechRecognition library for offline/no-quota scenarios.
