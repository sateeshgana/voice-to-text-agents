Who are your primary users and what devices do they use?

This shapes the UI layout and recording experience significantly.

📱

Mobile First

Most users on phones — thumb-friendly large buttons, tap-to-record, portrait layout. Best for field workers, rural users, WhatsApp-style sharing.

💻

Desktop First

Office/professional users — larger text preview area, keyboard shortcuts, side-by-side layout. Best for data entry, documentation, transcription work.

↔️

Fully Responsive

Equal experience on both — responsive design that adapts. Slightly more build effort but covers all users. Recommended for public-facing tools.
